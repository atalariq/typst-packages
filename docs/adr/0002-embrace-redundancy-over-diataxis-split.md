# Don't split how-to from explanation inside a laprak's Langkah Kerja

`language-rules.md`'s own writing-style research (Diátaxis) argues a how-to
should be "action and only action," with rationale moved to a separate
explanation page — mixing the two is called out there as "at the heart of a
vast number of problems in documentation." A laprak's `Langkah Kerja`
section deliberately does the opposite: it may restate relevant theory
inline instead of only cross-referencing `Dasar Teori`. This was a
conscious choice for Codelabs-style reading flow over strict mode
separation — forcing a reader to flip between sections costs more than the
redundancy does, for a report this short. Don't "fix" this by splitting
`Langkah Kerja` down to pure action later without revisiting the trade-off.
