# Atalariq's Typst Package

## Installation

```bash
mkdir -p ~/.local/share/typst/packages
ln -sf $(realpath .)/packages ~/.local/share/typst/packages/atalariq
```

## Usage
```typ
#import "@atalariq/<package-name>:<version>": *

// rest of your document
```
