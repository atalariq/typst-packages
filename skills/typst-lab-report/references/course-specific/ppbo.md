# PPBO — Pemrograman Berorientasi Objek

## Course Info
- Course: Pemrograman Berorientasi Objek
- Code: PPBO
- Platform: Java (OpenJDK)
- Semester: 4 (D4 TRPL UGM)

## Report Structure
- Standard lab report: Cover → Tujuan → Dasar Teori → Hasil dan Pembahasan → Kesimpulan → Daftar Pustaka → Lampiran
- Bagian B (Implementasi Program) maps to `= Hasil dan Pembahasan`:
  - `== Fitur Minimal` — setiap fitur sebagai subsection (`===`)
  - `== Implementasi Konsep OOP` — setiap konsep sebagai subsection (`===`)
- Bagian C (Analisis) is a separate written task, not part of the report body.
- Lampiran berisi source code lengkap (via `#include-code()`).

## Dasar Teori
- Wajib mencakup: Encapsulation, Inheritance, Polymorphism (Overloading & Overriding), Abstract Class, Interface
- Setiap konsep: 1 paragraf definisi + 1 paragraf relevansi ke game development
- Gunakan referensi buku OOP Java atau dokumentasi Oracle resmi

## Code Citation
- Gunakan `#include-code()` dari `@atalariq/code` package
- `line-range` end-exclusive (Python slice semantics)
- Setiap snippet harus merupakan unit logis yang utuh (satu method/konstruktor utuh)
- Language: Java (lang: "java")

## Language
- Formal Indonesian (EYD V)
- Passive voice throughout
- Istilah teknis Inggris tanpa padanan Indonesia: italic pada first use per section
- Contoh: `_encapsulation_`, `_inheritance_`, `_polymorphism_`, `_overloading_`, `_overriding_`, `_abstract class_`, `_interface_`

## Grading Focus
- Ketepatan identifikasi konsep OOP di kode (60%)
- Penjelasan hubungan antar kelas (20%)
- Kejelasan contoh code snippet (20%)
