# 📋 Laporan Praktikum — Kriteria Penilaian (PPW1)

## Bobot Penilaian

1. **Kerapian (20%)** — Format, struktur, konsistensi penulisan
2. **Penjelasan (60%)** — Kedalaman analisis, bukan deskripsi permukaan
3. **Gambar (10%)** — Screenshot/output dengan caption deskriptif
4. **Bonus (10%)** — Ekstra (inisiatif, kelengkapan, dll.)

---

## Struktur Wajib

1. **Cover**
2. **Tujuan Praktikum**
3. **Dasar Teori** (cukup 1 paragraf per konsep, singkat dan jelas)
4. **Hasil dan Pembahasan** (langsung ke Tugas Praktikum, tanpa mencantumkan latihan)
5. **Kesimpulan**
6. **Daftar Pustaka** (sitasi format IEEE)

## Ketentuan Tambahan

- Kumpulkan **link repository GitHub**
- **Hasil latihan praktikum** tidak perlu dimasukkan ke laporan, tapi source code tetap harus ada di repo GitHub
- Sertakan juga link **Figma** (jika ada desain UI/UX)

## Tips

- Gunakan bahasa yang jelas dan to the point
- Pastikan hasil & pembahasan fokus menjelaskan tugas praktikum yang dikerjakan
- Cek kembali format penulisan sebelum dikumpulkan
